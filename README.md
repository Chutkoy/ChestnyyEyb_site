# 🎩 Честный Эйб (Chestnyy Eyb)

Исходный код официального сайта инди-студии разработки мобильных игр и приложений **«Честный Эйб»**.

## 🛹 О студии
Студия названа в честь 16-го президента США Авраама Линкольна, известного под прозвищем «Честный Эйб» (Honest Abe). 
Это независимая студия одного человека (Чуткого), который в одиночку пишет код, создает пиксель-арт, придумывает сюжеты и отвечает на письма.

**Наша философия:** Создание честных, глубоких и качественных игр и приложений для Android.

## 🎮 Проекты
*   **HeroSkAge (В разработке):** Главная игра студии. Вселенная уличных экстремалов (скейтборды, BMX, ролики). Герои противостоят злой корпорации `Eidovyrex`.
*   **Рассказы дядюшки Эйба:** Читалка коротких авторских рассказов.
*   **КвадроТактика:** Тактическая игра в кубики.

## 🛠 Технологии
Сайт написан на чистом стеке без тяжелых фреймворков для максимальной производительности и SEO:
*   **HTML5**
*   **CSS3** (Vanilla)
*   **JavaScript** (Vanilla)
